# 芦苇斑块跨图幅调查系统

湿地调查员核清跨图幅芦苇斑块的 Web 工具：按图幅行列上传/替换 16×16 的 0/1 掩膜 CSV，
自动跨片缝连通、编号、统计全图格数。Flask + SQLite，Docker Compose 一键启动。

## 快速开始

```bash
docker compose up --build      # 打开 http://localhost:8080
```

本地开发（Python 3.11+）：

```bash
pip install -r requirements.txt -r requirements-dev.txt
python wsgi.py                 # http://localhost:8000
pytest tests/ -q               # 运行自测
```

## 规则约定

- 每片图幅 16×16，CSV 为 16 行、每行 16 个 `0`/`1`（逗号分隔；兼容无逗号的 16 位串）。
- 全图坐标：图幅 `(sr, sc)` 的片内格 `(r, c)` → 全图 `(sr*16+r, sc*16+c)`，**行、列号均从 0 起计**。
- 值为 1 的格子共边（四邻）相连，片缝两侧同样相连。
- **斑块号** = 该斑块最北一行中最西一格的全图行列号，形如 `(8,10)`。
- 同位置重复上传即替换；其他图幅的片内连通关系不变，跨片拆并引起的编号与总格数随新版本一并更新。

## 网页功能

- **上传/替换**：表单填图幅行列 + 选 CSV 文件（或直接粘贴文本）。校验失败返回 400，已发布数据不变。
- **在线试跨片合并/拆开**：首页三个演示按钮——
  ① 载入两片跨缝相接的条带 → 全图合并为 1 个斑块（12 格）；
  ② 替换右片使条带错开 → 拆成 2 个斑块（各 6 格）；
  ③ 清空全部图幅。
- **图幅列表 / 斑块汇总 / 全图预览**：颜色区分斑块，悬停看坐标与总格数。
- **选片查看**：`/sheet/<行>/<列>` 展示 16×16 网格，每个芦苇格标注斑块号，汇总表给出片内各斑块的片内格数与全图总格数。
- **JSON API**：`GET /api/state`、`GET /api/sheet/<行>/<列>`（均带版本号）。

## 设计要点（对应需求）

- **掩膜与成果一并切换**：每次交片产生一个单调递增的版本，掩膜（`sheets`）、
  斑块成果（`patches`、`cell_patches`）在同一事务内写入并翻转 `meta.version`，
  查询永远只读某个完整版本，不会看到混搭。
- **重算期间可查完整旧成果**：先在事务外基于当前发布版本重算，算完才进写事务提交；
  重算进行中所有查询仍读到旧版本的完整成果。
- **失败的交片不改已发布数据**：CSV 校验在写库前完成，失败直接 400；
  写库任何异常整体回滚。
- **并发按实际入库顺序生效**：进程内写锁串行化 + `BEGIN IMMEDIATE` 与版本号校验兜底，
  版本被抢先则基于最新成果重试，最终效果等同于按提交顺序依次应用。
- **换片沿用他片连通关系**：重算只针对全量掩膜的连通分量，未改动图幅的片内连通结果自然保持；
  跨片拆并只通过新版本的编号与总格数体现。

## 实测结果（交付前自测）

- `pytest tests/ -q`：**17 passed**。覆盖：单片编号规则（最北行最西格、北优先于西）、
  对角不相连、纵/横片缝合并、替换导致拆开与合并、编号与总格数联动更新、
  非法 CSV（行数/列数/非法值/空）全部 400 且版本与成果不变、越界图幅位置拒绝、
  8 线程并发交片（版本恰好 +8、掩膜与成果同版本）、同片并发替换可串行化、
  重算进行中旧成果可读、演示接口 merge/split/clear、页面渲染。
- gunicorn（1 worker × 8 线程，与容器内一致）实机冒烟：
  - 两片跨缝条带 → `{"id":"8,10","size":12}`；替换右片 → `(8,10)`、`(9,16)` 各 6 格；
  - 15 行 CSV → 400，状态保持 v3 不变；
  - 10 路并发 HTTP 交片 → 版本恰好 +10，12 片 11 斑块，数据一致；
  - 首页/片页 HTML 正常渲染斑块号与“全图共 12 格”。

## 待补事项

- 本环境无 Docker，`docker compose up` 未实际跑过；Dockerfile 与本地 gunicorn 冒烟
  使用同一启动命令（`gunicorn --workers 1 --threads 8 wsgi:app`），请在有 Docker 的
  机器上做一次 `docker compose up --build` 验证。
- 历史版本永久保留，未做清理；数据量大时可加旧版本裁剪（保留最近 N 版）。
- 重算为全量并查集，千片级仍无压力；若图幅规模极大可改增量合并/分裂。
- 多副本水平扩展时写锁仅在单进程内有效（数据库侧版本校验仍保证正确性，但冲突重试会增多）；
  需要多副本时建议固定单写实例或引入队列。
- 行列号从 0 起计为本实现的明确约定；若业务习惯 1 起计，需统一调整展示层。
- 暂未提供“删除单片”接口（可用全 0 掩膜替换达到同样效果）。
